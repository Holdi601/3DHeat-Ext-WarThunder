# Документ меча {#the-match-document}

![Почетак синтетичког документа меча, и његови кључеви](../assets/img/match-document.svg)

`<match>.match.json` држи све што реплеј каже, а што није ред табеле. Картица
приказача Меч чита њега.

## Битка {#the-battle}

| Кључ | Шта је |
|---|---|
| `format`, `version` | `heat3d-wt-replay-match`, `2` |
| `match`, `map`, `level` | ид меча (као у називу датотеке); ид мапе; датотека нивоа коју користите |
| `mission`, `missionKey` | назив мисије и њен кључ у игриним текстуалним датотекама |
| `battleClass`, `environment`, `weather` | како их даје заглавље |
| `sessionId`, `server` | ид сесије битке; сервер |
| `replayVersion`, `flightLayout` | верзија формата реплеја; прочитан распоред пакета лета (`2025` или `2026`) |
| `files` | прочитане датотеке реплеја (једна, или делови серверског реплеја) |
| `started`, `timePlayed`, `replayEnd` | време почетка (ISO, UTC); прошле секунде, из резултата; секунде последњег пакета реплеја |
| `author`, `authorUserId` | снимајући играч и његов Gaijin ид (клијентски реплеји) |
| `teams` | тимови у бици (`1`, `2`) |
| `result` | `winner`, `status` (`success` или `fail`, исход аутора), `authorTeam`, `teams` ([Економија](economy.md)) |
| `vehicleNames` | одакле су дошли називи возила (ваша инсталација) и њихов језик |
| `conventions` | јединице и знаци табеле: осе, време, живот, трак, жив, валљање, и још |

## Све остало {#everything-else}

| Кључ | Шта је |
|---|---|
| `battle`, `difficulty`, `gameMode` | режим битке: `difficulty` `AB` / `RB` / `SB` (и његов назив и бајт из заглавља), `gameMode` `ground` / `air` / `naval`, режим мисије (`Dom`, `Conq`, `Bttl`, `I2M`, ...) и његов енглески назив из ваше инсталације (`Domination`, `Enduring Confrontation`), дозвољене врсте јединица (видите [Режим битке](ground.md#battle-mode)) |
| `settings` | blk мисије после заглавља: режим, окружење, време, границе поена и времена, државе, дозвољене врсте јединица, ветар, и `stars` (географска ширина, дужина, датум, локално време) |
| `sky` | први `CustomWeatherParams`: правац сунца и месеца, ветар, боје неба, помаци облака |
| `players`, `slots` | ред резултата по играчу (убиства, убиства на копну, смрти, асистенције, поени, заузимања, одред, клан, држава, састав, ид-еви којима је возио); слотови играча реплеја (име, ид корисника, тим) |
| `units` | сваки ентитет јединице који је реплеј створио: eid, uid, шаблон, возило, врста, тип, тим, играч, назив у мисији, кад је створен и уклоњен, где је створен, које компоненте нису могле да се прочитају |
| `objects` | именовани објекти мисије: зоне заузимања и аеродроми са положајем и величином, обриси аеродрома као тачке, области појављивања |
| `objectives` | циљеви битке, сваки с `type` (`capture_zone`, `airfield`, `helipad`, `base`, `spawn`, `convoy_spawn`, `battle_area`, `bombing_target`, `exit_zone`, `kill_area`, `rearm_zone`), `team` (1 или 2 из реплеја, празно за обе), `name` (зона заузимања њено слово, `A`), `shape` (`sphere`, `cylinder`, `box`, `point`, `points`, `outline`) с `position`, `radius` / `height` / `size` и `heading`, `source` (`replay` или `mission`) и шта је још познато (видите [Циљеви](objectives.md)) |
| `kills`, `hits`, `modulesDestroyed` | с називима и возилима обе стране; убиства с енглеским називом оружја |
| `weapons` | свака ракета, пројектил, бомба, торпедо, додатни резервоар и одбачени терет: када, где је испуштено (положај, став, брзина), којом јединицом (најближа у 300 m и 1,5 s), колико узорака лета, где је последњи пут виђено, када је уклоњено |
| `explosions`, `flak` | `PlayExplosionVisual` (положај, правац, врста) и `PlayFlakExplosionVisual` (положај) |
| `awards` | награде снимајућег играча (`TextStreak`: first_blood, низови, бројачи изазова) |
| `detections`, `unitStates` | парови `UnitDetected` јединица; порука (0xF093) с положајем, ставом и брзином јединице, чије значење није познато |
| `authorInstruments` | вредности кабине снимајућег играча (`ReplayCockpitParams`) по броју мерача, највише једна у секунди; `known` именује сваки број који је овај реплеј послао (назив, јединица, како је проверено), `notNamed` остале |
| `scoreboard` | статистика сваког играча при свакој промени (убиства, смрти, асистенције, поени, AI убиства, поморска убиства, зоне, штета, избегнуте ракете, одред), и резултат сваког тима и вероватни тикети током времена (видите [Подаци рефлексије](aircraft.md#reflection-data)) |
| `economy` | сребрни лавови битке и истраживачки поени (видите [Економија](economy.md)): збирови, по играчу, по возилу, множитељи, победник, провере |
| `entityMessages` | ентитетске поруке (0x20) по броју класе: број, шаблони циљева, величине |
| `chat` | сваки ред ћаскања |
| `triggers`, `hints`, `missionProgress` | радње скрипте мисије (RunTriggerAction), њени савети, поруке напретка |
| `camera` | поља реплеј камере снимајућег играча сваких 0,25 s онако како су послата (табела то има као трак) |
| `projectileHitReplays` | сопствени погоци снимајућег играча и погађање њега, с оружјем и муницијом и њиховим енглеским називима |
| `results` | цео блок резултата онако како га је игра записала |
| `counts` | редови, догађаји, животи, врсте, узорци, ентитети по шаблону, оружја, пакети прочитани и неочитани, сви ид-еви порука виђени и они неочитани, одбачени узорци |
| `trackBreaks` | сваки рез трака за корак бржи од онога што јединица може: где, колико далеко, колико брзо, и шта је највероватније |
| `selfCheck` | провере наведене у [Како чита реплеј](how-it-reads.md), израчунате при сваком претварању; `stepSpeed` даје по врсти брзину између узастопних редова трака онако како их приказач спаја (медијана, 99. перцентил, највиша, и кораци бржи од могућег, што мора бити 0) |
