# Μετατροπή replay {#converting-replays}

Αποτέλεσμα: ένα αρχείο `.3dheat` ανά μάχη (η προεπιλογή), ή χωριστά αρχεία με
`--loose`.

## Βήμα προς βήμα {#step-by-step}

1. **Ενεργοποιήστε τα replays.** Το War Thunder αποθηκεύει τα replays του πελάτη στον
   φάκελο `Replays` του παιχνιδιού, όταν η αποθήκευση replays είναι ενεργή στις
   επιλογές του, για παράδειγμα
   `C:\Program Files (x86)\Steam\steamapps\common\War Thunder\Replays`.
   Ένα replay διακομιστή που αποθηκεύτηκε από τη σελίδα replays του παιχνιδιού (ένα zip
   με `0000.wrpl`, `0001.wrpl`, ...) μπορεί επίσης να μετατραπεί.
2. **Ανοίξτε ένα τερματικό** σε φάκελο όπου μπορούν να γραφτούν τα αποτελέσματα
   ([Πριν ξεκινήσετε](before-you-start.md)).
3. **Μετατρέψτε:**

   ```bash
   heat3d-wt-replay "<War Thunder>/Replays" -o out
   heat3d-wt-replay a.wrpl b.wrpl -o out           # αρχεία, φάκελοι, ή και τα δύο
   heat3d-wt-replay battle.zip -o out              # το zip ενός replay διακομιστή
   heat3d-wt-replay a.wrpl -o out --loose          # χωριστά αρχεία αντί για ένα .3dheat
   ```

   Το `out` δημιουργείται μέσα στον φάκελο όπου είναι το τερματικό σας.
4. **Διαβάστε τι λέει.** Πρέπει να δείτε μία γραμμή ανά μάχη.
5. **Άνοιξέ το:** φορτώστε το `out/<map>/<match>.3dheat` στον προβολέα 3DHeat
   ([Φόρτωση ενός αρχείου](https://holdi601.github.io/3DHeat/container.html#loading-one)).

![Μια εκτέλεση σε ένα συνθετικό replay: ένα .3dheat, --loose, ένα χαλασμένο αρχείο, ένας άδειος φάκελος](../assets/img/convert.svg)

Η εικόνα είναι μια εκτέλεση σε ένα replay που φτιάχνουν τα τεστ μέσα στον κώδικα
(χωρίς πραγματικό replay και χωρίς εγκατάσταση):

- `ok <file>`: μια μάχη μετατράπηκε (με `--loose`: `ok <table> <match document>`)·
- `failed <file>: <why>`: ένα αρχείο που δεν μπόρεσε να διαβαστεί (κωδικός εξόδου 1·
  τα υπόλοιπα μετατρέπονται κανονικά)·
- `no .wrpl files given`: τίποτα να μετατραπεί (κωδικός εξόδου 2)·
- `note: ...`: για παράδειγμα ότι δεν βρέθηκε εγκατάσταση του War Thunder για να
  ονομαστούν τα οχήματα.

## Επιλογές {#options}

| Επιλογή | Προεπιλογή | Τι κάνει |
|---|---|---|
| `replays` (ένα ή περισσότερα) | - | αρχεία `.wrpl`, φάκελοι με αυτά (ο ίδιος ο φάκελος, όχι οι υποφάκελοί του), ή zip με αυτά (replay διακομιστή: τα μέρη `.wrpl` του αποσυμπιέζονται σε προσωρινό φάκελο) |
| `-o`, `--out` | υποχρεωτικό | πού γράφεται: ένας φάκελος ανά χάρτη μέσα του |
| `--game FOLDER` | βρέθηκε | ο φάκελος του War Thunder του οποίου το κείμενο ονομάζει οχήματα, όπλα και πυρομαχικά, και των οποίου οι πίνακες τιμολογούν την [οικονομία](economy.md)· επίσης `HEAT3D_WT_GAME` |
| `--no-smoothing` | ανενεργό | κράτα τα δείγματα των άλλων μονάδων, όπως τα έχει το replay (με dead reckoning και λήψη) ([Dead reckoning](aircraft.md#dead-reckoning-and-the-smoother)) |
| `--container` | ενεργό | συσκεύασε κάθε μάχη σε ένα αρχείο `.3dheat` |
| `--loose` | ανενεργό | κράτα κάθε μάχη ως χωριστά αρχεία (πίνακας, έγγραφο αγώνα, βοηθητικά αρχεία) |
| `--version` | - | τυπώστε `heat3d-wt-replay <έκδοση>` και σταμάτα |
| `-h`, `--help` | - | τυπώστε τις επιλογές και σταμάτα |

Μια μάχη που μετατρέπεται ξανά γράφεται ξανά. Οι επιλογές όπως τις τυπώνει το
πρόγραμμα: [Αναφορά εντολών](../cli-reference.md).

## Ποια αρχεία είναι μία μάχη {#which-files-are-one-battle}

Κάθε μάχη γίνεται ένα αρχείο,
`out/<map>/<map>_<AB|RB|SB>_<mode>_<start, UTC>_<session id>.3dheat`. Τα AB, RB
και SB είναι οι σύντομες μορφές του παιχνιδιού για τις μάχες arcade, realistic και
simulator· το `<mode>` είναι η λειτουργία της αποστολής όπως την κωδικοποιεί το παιχνίδι
(`Conq4` Conquest #4, `Dom` Domination, `Bttl` Battle· βλ.
[Λειτουργία μάχης](ground.md#battle-mode))· κάθε μέρος λείπει όταν το replay δεν το
ονομάζει. Τα μέρη ενός replay διακομιστή (`0000.wrpl`, `0001.wrpl`, ...) διαβάζονται
μαζί ως μία μάχη· ένα replay πελάτη και τα μέρη του διακομιστή για την ίδια μάχη είναι
δύο εγγραφές και μένουν δύο.

## Κωδικός εξόδου {#exit-status}

`0` όταν μετατράπηκε κάθε μάχη, `1` όταν απέτυχε κάποια (οι υπόλοιπες μετατρέπονται
κανονικά), `2` όταν δεν βρέθηκε αρχείο replay ανάμεσα στα ορίσματα.
