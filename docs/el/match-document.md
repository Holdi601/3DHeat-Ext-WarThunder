# Το έγγραφο αγώνα {#the-match-document}

![Η αρχή ενός συνθετικού εγγράφου αγώνα, και τα κλειδιά του](../assets/img/match-document.svg)

Το `<match>.match.json` κρατά όλα όσα λέει το replay και που δεν είναι γραμμή του
πίνακα. Την καρτέλα Αγώνας του προβολέα τη διαβάζει από εδώ.

## Η μάχη {#the-battle}

| Κλειδί | Τι είναι |
|---|---|
| `format`, `version` | `heat3d-wt-replay-match`, `2` |
| `match`, `map`, `level` | το αναγνωριστικό του αγώνα (όπως στο όνομα αρχείου)· το αναγνωριστικό του χάρτη· το αρχείο επιπέδου που χρησιμοποιεί |
| `mission`, `missionKey` | το όνομα της αποστολής και το κλειδί της στα αρχεία κειμένου του παιχνιδιού |
| `battleClass`, `environment`, `weather` | όπως τα δίνει η κεφαλίδα |
| `sessionId`, `server` | το αναγνωριστικό συνεδρίας της μάχης· ο διακομιστής |
| `replayVersion`, `flightLayout` | η έκδοση της μορφής του replay· η διάταξη των πακέτων πτήσης που διαβάστηκε (`2025` ή `2026`) |
| `files` | τα αρχεία replay που διαβάστηκαν (ένα, ή τα μέρη ενός replay διακομιστή) |
| `started`, `timePlayed`, `replayEnd` | ώρα έναρξης (ISO, UTC)· δευτερόλεπτα παιχνιδιού, από τα αποτελέσματα· δευτερόλεπτα του τελευταίου πακέτου του replay |
| `author`, `authorUserId` | ο παίκτης που καταγράφει και το αναγνωριστικό Gaijin του (replays πελάτη) |
| `teams` | οι ομάδες της μάχης (`1`, `2`) |
| `result` | `winner`, `status` (`success` ή `fail`, το αποτέλεσμα του συντάκτη), `authorTeam`, `teams` ([Οικονομία](economy.md)) |
| `vehicleNames` | από πού ήρθαν τα ονόματα των οχημάτων (η εγκατάστασή σας) και η γλώσσα τους |
| `conventions` | οι μονάδες και τα σημάδια του πίνακα: άξονες, χρόνος, life, track, alive, roll, και άλλα |

## Όλα τα υπόλοιπα {#everything-else}

| Κλειδί | Τι είναι |
|---|---|
| `battle`, `difficulty`, `gameMode` | η λειτουργία της μάχης: `difficulty` `AB` / `RB` / `SB` (και το όνομά της, και το byte της κεφαλίδας), `gameMode` `ground` / `air` / `naval`, η λειτουργία της αποστολής (`Dom`, `Conq`, `Bttl`, `I2M`, ...) και το αγγλικό όνομά της από την εγκατάστασή σας (`Domination`, `Enduring Confrontation`), οι επιτρεπόμενοι τύποι μονάδων (βλ. [Λειτουργία μάχης](ground.md#battle-mode)) |
| `settings` | το blk της αποστολής μετά την κεφαλίδα: λειτουργία, περιβάλλον, καιρός, όρια σκορ και χρόνου, χώρες, επιτρεπόμενοι τύποι μονάδων, άνεμος, και `stars` (γεωγραφικό πλάτος, μήκος, ημερομηνία, τοπική ώρα) |
| `sky` | το πρώτο `CustomWeatherParams`: η διεύθυνση του ήλιου και του φεγγαριού, ο άνεμος, τα χρώματα του ουρανού, οι μετατοπίσεις των σύννεφων |
| `players`, `slots` | η γραμμή των αποτελεσμάτων ανά παίκτη (σκοτωμοί, χερσαίοι σκοτωμοί, θάνατοι, βοηθήματα, σκορ, καταλήψεις, ομάδα, σύλλογος, χώρα, σύνθεση, τα uids που οδήγησαν)· οι θέσεις παικτών του replay (όνομα, αναγνωριστικό χρήστη, ομάδα) |
| `units` | κάθε οντότητα μονάδας που δημιούργησε το replay: eid, uid, template, vehicle, kind, type, team, player, όνομα αποστολής, πότε δημιουργήθηκε και αφαιρέθηκε, πού δημιουργήθηκε, ποια στοιχεία δεν μπόρεσαν να διαβαστούν |
| `objects` | τα ονομασμένα αντικείμενα της αποστολής: ζώνες κατάληψης και αεροδρόμια με τη θέση και το μέγεθός τους, τα περιγράμματα των αεροδρομίων ως σημεία, περιοχές εμφάνισης |
| `objectives` | οι στόχοι της μάχης, καθένας με `type` (`capture_zone`, `airfield`, `helipad`, `base`, `spawn`, `convoy_spawn`, `battle_area`, `bombing_target`, `exit_zone`, `kill_area`, `rearm_zone`), `team` (το 1 ή 2 του replay, κενό για τους δύο), `name` (μια ζώνη κατάληψης το γράμμα της, `A`), `shape` (`sphere`, `cylinder`, `box`, `point`, `points`, `outline`) με `position`, `radius` / `height` / `size` και `heading`, `source` (`replay` ή `mission`) και ό,τι άλλο είναι γνωστό (βλ. [Στόχοι](objectives.md)) |
| `kills`, `hits`, `modulesDestroyed` | με ονόματα και οχήματα και των δύο πλευρών· οι σκοτωμοί με το αγγλικό όνομα του όπλου |
| `weapons` | κάθε πύραυλος, βλήμα, βόμβα, τορπίλη, εξωτερική δεξαμενή και πεταμένο φορτίο: πότε, πού απελευθερώθηκε (θέση, στάση, ταχύτητα), από ποια μονάδα (η πλησιέστερη μέσα σε 300 m και 1,5 s), πόσα δείγματα πτήσης, πού φάνηκε τελευταία, πότε αφαιρέθηκε |
| `explosions`, `flak` | `PlayExplosionVisual` (θέση, κατεύθυνση, είδος) και `PlayFlakExplosionVisual` (θέση) |
| `awards` | τα βραβεία του παίκτη που καταγράφει (`TextStreak`: first_blood, σερί, μετρητές προκλήσεων) |
| `detections`, `unitStates` | ζεύγη μονάδων `UnitDetected`· ένα μήνυμα (0xF093) με τη θέση, τη στάση και την ταχύτητα μιας μονάδας, του οποίου η σημασία δεν είναι γνωστή |
| `authorInstruments` | οι τιμές της κάμπινας του παίκτη που καταγράφει (`ReplayCockpitParams`) ανά αριθμό οργάνου, το πολύ μία ανά δευτερόλεπτο· το `known` ονομάζει κάθε αριθμό που έστειλε αυτό το replay (όνομα, μονάδα, πώς ελέγχθηκε), το `notNamed` τους υπόλοιπους |
| `scoreboard` | τα στατιστικά κάθε παίκτη κάθε φορά που άλλαξαν (σκοτωμοί, θάνατοι, βοηθήματα, σκορ, σκοτωμοί AI, ναυτικοί σκοτωμοί, ζώνες, ζημιά, αποφυγές πυραύλων, ομάδα)· και το σκορ κάθε ομάδας και τα πιθανά εισιτήρια με τον χρόνο (βλ. [Δεδομένα αντανάκλασης](aircraft.md#reflection-data)) |
| `economy` | τα Silver Lions και οι πόντοι έρευνας της μάχης (βλ. [Οικονομία](economy.md)): σύνολα, ανά παίκτη, ανά όχημα, οι πολλαπλασιαστές, ο νικητής, οι έλεγχοι |
| `entityMessages` | τα μηνύματα οντοτήτων (0x20) ανά αριθμό κλάσης: πλήθος, πρότυπα στόχων, μεγέθη |
| `chat` | κάθε γραμμή συνομιλίας |
| `triggers`, `hints`, `missionProgress` | οι ενέργειες του σεναρίου της αποστολής (RunTriggerAction), οι υποδείξεις της, τα μηνύματα προόδου της |
| `camera` | τα πεδία της κάμερας replay του παίκτη που καταγράφει κάθε 0,25 s, όπως στάλθηκαν (ο πίνακας την έχει ως διαδρομή) |
| `projectileHitReplays` | τα δικά του χτυπήματα του παίκτη που καταγράφει και τα χτυπήματα πάνω του, με το όπλο και τα πυρομαχικά και τα αγγλικά ονόματά τους |
| `results` | όλο το blk των αποτελεσμάτων όπως το έγραψε το παιχνίδι |
| `counts` | γραμμές, γεγονότα, ζωές, είδη, δείγματα, οντότητες ανά πρότυπο, όπλα, πακέτα που διαβάστηκαν και δεν διαβάστηκαν, κάθε αναγνωριστικό μηνύματος που φάνηκε και όσα δεν διαβάστηκαν, δείγματα που πετάχτηκαν |
| `trackBreaks` | κάθε κοπή διαδρομής για βήμα πιο γρήγορο απ' όσο μπορεί η μονάδα: πού, πόσο μακριά, πόσο γρήγορα, και τι είναι πιθανότερα |
| `selfCheck` | οι έλεγχοι που αναφέρονται στο [Πώς διαβάζει ένα replay](how-it-reads.md), υπολογισμένοι σε κάθε μετατροπή· το `stepSpeed` δίνει ανά είδος την ταχύτητα ανάμεσα σε διαδοχικές γραμμές μιας διαδρομής όπως τις ενώνει ο προβολέας (διάμεσος, 99ο εκατοστημόριο, υψηλότερη, και βήματα γρηγορότερα από το εφικτό, που πρέπει να είναι 0) |
