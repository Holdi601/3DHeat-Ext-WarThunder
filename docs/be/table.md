# Табліца {#the-table}

![Табліца сінтэтычнага запісу ў скарочаным выглядзе](../assets/img/table.svg)

Адзін радок на адлік або падзею, 105 слупкоў ([Спіс слупкоў](../columns.md), ствараецца з кода); у калонтытуле, пад `heat3d`, - інструкцыі
праглядальніка па чытанні, таму праглядальніку не трэба запаўняць ніякую форму.

| Слупок | Што |
|---|---|
| `time` | секунды па ўласным гадзінніку запісу |
| `event` | `position`; радкі падзей ляжаць на трэку ў свой момант (паміж двума адлікамі - на лініі паміж імі); `kill` (у забойцы), `death` (у ахвяры), `hit_critical` / `hit_severe` (у адзінцы, у якую трапілі), `module_destroyed` (у адзінцы), `launch` (у адзінцы, што выпусціла зброю), `impact` (апошні адлік зброі, калі яе выдалілі адразу пасля); `explosion` і `flak` (0xD08E, 0xD01F) у іх пазіцыі, від `effect`, без трэка, з напрамкам выбуху, калі ён ёсць; `shot` (снарад, што трапіў, у стралка), `gun_shot`, `fire_start`, `fire_stop` (чарга гарматы, а не машына ў агні), `fire_on`, `fire_off` (машына ў агні, гл. [Пажары машын](hits.md#vehicle-fires)), `reward` (заробленыя Silver Lions і ачкі даследавання, гл. [Эканоміка](economy.md)), `dead`, `bailout`, `repair`, `rearm`, `bullet_rearm`, `reload` (гл. [Паведамленні адзінкам](how-it-reads.md#messages-to-units)); `despawn`: апошні радок трэка, чыя адзінка знікла да канца запісу (гл. [Канец трэка](ground.md#end-of-a-track)) |
| `track` | тое, што праглядальнік малюе як адно: адно жыццё адзінкі або палёт адной зброі - `<player or vehicle> #<hex>` (праглядальнік паказвае імя без часткі `#`) |
| `x`, `y`, `z` | метры гульні: x усход, y уверх, z поўнач (падказкі люструюць z, таму поўнач не малюецца на поўдні) |
| `player` | імя гульца; адзінка ШІ - `<VehicleName> #<uid>` (напрыклад, `F-15A #204`); `uid <n>`, калі нічога яе не называе; для зброі - хто яе выпусціў |
| `userId`, `team` | id Gaijin гульца і каманда (`1`, `2`) |
| `ai`, `isPlayer` | `ai` true для кожнай адзінкі, якой не кіруе ніводны ўліковы запіс гульца (адзінкі місіі, самалёты ШІ, наземныя мэты, зенітныя гарматы, караблі без гульца, запаўняльнікі), `isPlayer` - наадварот: гулец - гэта адзінка, сутнасць якой называе слот гульца з id Gaijin. У зброі - значэнні яе пускавой адзінкі; пуста, калі невядома |
| `match` | id матча (`match` дакумента матча), у кожным радку; падказкі прызначаюць яго як сесію, таму два загружаныя запісы ніколі не злучаць трэкі |
| `life` | `uid#n`: трэк адной адзінкі, разрэзаны там, дзе uid пераходзіць да іншай адзінкі, адзінка рухаецца хутчэй, чым можа (адраджэнне, перазарадка, перамяшчэнне гульнёй, папраўка далёкай адзінкі кліентам; гл. Тэлепарты ў [Як чытаецца запіс](how-it-reads.md#what-is-read-and-the-check)) або доўга не бачная; `w<hex>` - палёт зброі (`w<hex>#n` пасля разрэзу) |
| `uid` | id адзінкі ў запісе |
| `kind` | `aircraft`, `helicopter`, `tank`, `apc`, `spaa`, `truck`, `ship`, `boat`, `structure`, `train` (трамвай або чыгуначны вагон, які ставіць узровень, гл. [Адзінкі сцэны](objectives.md#scene-units-trams-and-rail-wagons)); зброя `missile`, `rocket`, `bomb`, `torpedo`, `payload`, `jettisoned`; `camera` - камера запісу гульца, які вядзе запіс (гл. [Камера](ground.md#the-camera)) |
| `type` | уласны тып гульні, дзе яго называюць вынікі (`fighter`, `assault`, `destroyer`, `gun_boat`), інакш як `kind` |
| `Vehicle` | id машыны ў гульні (`f_15a`, `germ_flakpz_I_Gepard`), якому адпавядаюць фігуркі праглядальніка |
| `VehicleName`, `VehicleShortName`, `VehicleNameKey` | англійская назва машыны з лакалізацыі вашай усталёўкі (`Pz.Kpfw. III Ausf. J1`, кароткая `Pz.III J1`) і яе ключ (`germ_pzkpfw_III_ausf_J_0`); знакі краін шрыфта гульні прапускаюцца. Калі гульня нічога не называе або ўсталёўка не знойдзена, назва - гэта id, а ключ пусты |
| `mission` | назва адзінкі ў місіі (`t1_tank_05`, `t2_player03_0`) |
| `dirX`, `dirY`, `dirZ` | куды паказвае адзінка (вектар погляду): у самалётаў з арыентацыі лётнай мадэлі, у наземных адзінак і караблёў з іх уласнай, у зброі - уздоўж палёту |
| `heading`, `pitch`, `roll` | тое ж у градусах; heading - компас, па гадзіннікавай ад поўначы, pitch дадатны носам уверх, roll дадатны правым крылом уніз (лётная мадэль дасылае супрацьлеглы знак, гл. [Арыентацыя, праверана](aircraft.md#attitude-checked); у наземнай адзінкі - правым бокам уніз). Падказкі кажуць пра гэта пад `conventions` |
| `turretYaw`, `gunPitch`, `turrets` | галоўная вежа танка - куды паказвае гармата, а не куды глядзіць гулец; значэнне запісу, абмежаванае хуткасцю прывада вежы і ўсталёўленае на лінію кожнага стрэлу галоўнай гарматы (гл. [Вежы](ground.md#turrets)): яе паварот адносна корпуса (градусы, па гадзіннікавай, калі глядзець зверху, дадатны, 0 - проста наперад) і тангаж яе гарматы адносна корпуса (градусы, уверх дадатны); `turrets` - кожная вежа машыны як `yaw pitch;yaw pitch;...` у яе ўласным парадку (нявыкарыстаны слот чытаецца як `0.00 0.00`). Танкі, ЗСУ, БТР і грузавікі, у запісах кліента і сервера; не караблі (гл. [Вежы](ground.md#turrets)) |
| `turretYawRaw`, `gunPitchRaw` | галоўная вежа, як яе дасылае запіс; `turretYaw` / `gunPitch` - гэта яна, абмежаваная хуткасцю прывада вежы і ўсталёўленая на лінію кожнага стрэлу галоўнай гарматы (гл. [Вежы](ground.md#turrets)) |
| `viewYaw`, `viewPitch` | куды глядзіць гулец (цэліць камерай) у свеце: градусы компаса (0 поўнач, па гадзіннікавай) і градусы ўверх, тая ж умова, што ў `aimHeading` / `aimPitch` (у адрозненне ад `turretYaw` / `gunPitch`, якія застаюцца адносна корпуса). Танк кожнага гульца ў запісе сервера, свой уласны ў запісе кліента; пуста, калі гулец нікуды не цэліць (усе чатыры float прыцэлу 0). Вежа ідзе за ім са сваёй хуткасцю павароту, таму яны адрозніваюцца, пакуль яна паварочваецца (гл. [Вежы](ground.md#turrets)) |
| `aimHeading`, `aimPitch`, `aimDistance` | уласны танк гульца, які вядзе запіс: куды ён цэліць (градусы компаса, градусы ўверх, адлегласць у м; 2000, калі ў прыцэле нічога няма); радкі камеры: куды цэліць гулец (heading, pitch) |
| `zoom` | радкі камеры: павелічэнне камеры (гл. [Камера](ground.md#the-camera)) |
| `difficulty`, `gameMode` | `AB`, `RB` або `SB` бою і `ground`, `air` або `naval`, у кожным радку (гл. [Рэжым бою](ground.md#battle-mode)) |
| `extrapolated` | адлік самалёта, які з'яўляецца экстрапаляцыяй кліента, а не атрыманым станам (гл. [Экстрапаляцыя](aircraft.md#dead-reckoning-and-the-smoother)); адлік бомбы, вылічаны ад яе выпуску (гл. Бомбы без запісаў палёту ў [Як чытаецца запіс](how-it-reads.md#what-is-read-and-the-check)) |
| `moved`, `xRaw`, `yRaw`, `zRaw`, `headingRaw`, `pitchRaw`, `rollRaw` | наколькі згладжвальнік зрушыў адлік (м), і ўласная пазіцыя і арыентацыя запісу (крэн са знакам табліцы) |
| `targetX`, `targetY`, `targetZ` | пункт траплення `shot` |
| `hitOutcome`, `hitFlags` | вынік `shot` па наземнай адзінцы: `kill`, `critical`, `penetration` або `nonpenetration` (адскочыў або спынены: запіс не адрознівае рыкашэт), з бітаў, якія сервер дасылае разам з трапленнем (`hitFlags`, неапрацаваныя); пуста, калі нічога не дасылаецца (самалёты, караблі). Гл. [Вынікі трапленняў](hits.md#hit-outcomes) |
| `hitShell` | сігнатура снарада `shot`: чатыры байты паведамлення пра трапленне (неапрацаваны hex); адна сігнатура можа азначаць розныя снарады (120- і 125-мм APFSDS маюць адну), таму яна захоўваецца неапрацаванай, не чытаецца як калібр |
| `ammoType`, `ammoName`, `ammoSlot`, `calibre` | боепрыпасы `shot`: іх тып (`APFSDS`, `APDS`, `HE`, `HEAT-FS`, `HESH`, `ATGM`...) і id (`125mm_3bm46`), дзе забойства называе слот стралка, інакш `explosive` (разрыў траплення) або `kinetic`; `weapon/slot` гарматы з яе перазарадак; калібр у мм з файлаў зброі ўсталёўкі. Гл. [Вынікі трапленняў](hits.md#hit-outcomes) |
| `rpm` | абароты рухавікоў самалёта (сярэдняе па рухавіках), як апошні раз дасланыя, у межах 2 с |
| `vx`, `vy`, `vz` | хуткасць самалёта, як яе дасылае яго запіс палёту (м/с, восі гульні; хуткасці вышэй за 500 м/с чытаюцца як 500) |
| `engine`, `afterburner`, `engineCondition` | рухавікі самалёта з яго запісу палёту: `off`, `starting`, `running`, `dead` (праз `/`, калі рухавікі розныя); форсаж 0-1; байт, які дасылаецца толькі пасля таго, як рухавік быў падбіты |
| `weaponName` | забойствы і смерці: зброя або боепрыпасы па-англійску з вашай усталёўкі (`AIM-120C-5 AMRAAM air-to-air missiles`, `Fragmentation incendiary tracer shell`) |
| `throttle`, `elevator`, `aileron`, `rudder`, `ammo` | толькі самалёт гульца, які вядзе запіс: газ 0-1,1 з кабіны (1,1 аварыйны ваенны рэжым або форсаж; інакш пятнаццатыя долі з яго запісу палёту), кіраванне -1..1 з яго запісу палёту (руль вышыні дадатны на сябе, элерон дадатны крэнам управа), астатак патронаў на зброю (`250 140 170`) |
| `ias`, `vario`, `fuel`, `manifoldPressure`, `gear`, `oilTemperature`, `headTemperature` | толькі самалёт гульца, які вядзе запіс, з кабіны: прыборная хуткасць і хуткасць пад'ёму (м/с), паліва, ціск у калектары (атм), шасі (0-1, 1 выпушчана), тэмпература алею і галоўкі цыліндраў, дзе ў кабіне ёсць прыбор |
| `speed` | м/с за каля дзвюх секунд трэка (вылічана тут; запіс не дасылае хуткасці іншых адзінак) |
| `alive` | 0 для адлікаў адзінкі пасля яе смерці (яе абломкі): у наземнай адзінкі або карабля - пакуль гульня іх не выдаліць або адліку не скончацца, у самалёта - не даўжэй за 60 с |
| `otherVehicle`, `otherLife` | ахвяра `shot`: яе машына і яе `life` |
| `hitLocalX`, `hitLocalY`, `hitLocalZ`, `hitDirX`, `hitDirY`, `hitDirZ` | пункт траплення `shot` ва ўласнай сістэме ахвяры (м; x наперад, y уверх, z улева; гл. [Паведамленні адзінкам](how-it-reads.md#messages-to-units)) і напрамак, адкуль прыйшоў стрэл, павернуты ў гэту сістэму тагачаснай арыентацыяй ахвяры |
| `hitPart`, `hitFlag` | паведамленне пра трапленне `shot`: яго слова часткі, як дасланае, і яго старшы байт |
| `cost_fired_sl`, `cost_lost_sl`, `earn_sl`, `earn_rp`, `rewardType`, `currency`, `econ_basis`, `won` | што бой каштаваў і прынёс, і хто выйграў: гл. [Эканоміка](economy.md) |
| `other`, `weapon` | забойствы: другі бок і зброя; трапленні: хто трапіў (з uid запісу, інакш з яго слота гульца), яго машына; пускі: зброя; знішчаныя модулі: хто апошні раз трапіў у адзінку ў межах 5 с раней, і `part <n>` |
