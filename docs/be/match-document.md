# Дакумент матча {#the-match-document}

![Пачатак сінтэтычнага дакумента матча і яго ключы](../assets/img/match-document.svg)

`<match>.match.json` трымае ўсё, што кажа запіс і што не з'яўляецца радком
табліцы. Яго чытае ўкладка «Матч» праглядальніка.

## Бой {#the-battle}

| Ключ | Што |
|---|---|
| `format`, `version` | `heat3d-wt-replay-match`, `2` |
| `match`, `map`, `level` | id матча (як у назве файла); id карты; файл узроўню, які ён выкарыстоўвае |
| `mission`, `missionKey` | назва місіі і яе ключ у тэкставых файлах гульні |
| `battleClass`, `environment`, `weather` | як іх дае загаловак |
| `sessionId`, `server` | id сесіі бою; сервер |
| `replayVersion`, `flightLayout` | версія фармату запісу; прачытаная раскладка пакетаў палёту (`2025` або `2026`) |
| `files` | прачытаныя файлы запісу (адзін або часткі запісу сервера) |
| `started`, `timePlayed`, `replayEnd` | час пачатку (ISO, UTC); секунд гульні, з вынікаў; секунд апошняга пакета запісу |
| `author`, `authorUserId` | гулец, які вёў запіс, і яго id Gaijin (запісы кліента) |
| `teams` | каманды ў баі (`1`, `2`) |
| `result` | `winner`, `status` (`success` або `fail`, вынік аўтара), `authorTeam`, `teams` ([Эканоміка](economy.md)) |
| `vehicleNames` | адкуль узяты назвы машын (ваша ўсталёўка) і іх мова |
| `conventions` | адзінкі і знакі табліцы: восі, час, жыццё, трэк, alive, крэн і іншае |

## Усё астатняе {#everything-else}


| Ключ | Што |
|---|---|
| `battle`, `difficulty`, `gameMode` | рэжым бою: `difficulty` `AB` / `RB` / `SB` (і яго назва, і байт загалоўка), `gameMode` `ground` / `air` / `naval`, рэжым місіі (`Dom`, `Conq`, `Bttl`, `I2M`, ...) і яго англійская назва з вашай усталёўкі (`Domination`, `Enduring Confrontation`), дазволеныя тыпы адзінак (гл. [Рэжым бою](ground.md#battle-mode)) |
| `settings` | blk місіі пасля загалоўка: рэжым, асяроддзе, надвор'е, абмежаванні ачкоў і часу, краіны, дазволеныя тыпы адзінак, вецер і `stars` (шырата, даўгата, дата, мясцовы час) |
| `sky` | першы `CustomWeatherParams`: напрамак сонца і месяца, вецер, колеры неба, зрушэнні аблокаў |
| `players`, `slots` | радок вынікаў на гульца (забойствы, наземныя забойствы, смерці, садзейнічанні, ачкі, захопы, атрад, клан, краіна, склад, uid, якімі ён кіраваў); слоты гульцоў запісу (імя, id карыстальніка, каманда) |
| `units` | кожная сутнасць адзінкі, створаная запісам: eid, uid, шаблон, машына, від, тып, каманда, гулец, назва ў місіі, калі створана і выдалена, дзе створана, якія кампаненты не ўдалося прачытаць |
| `objects` | названыя аб'екты місіі: зоны захопу і аэрадромы з пазіцыяй і памерам, контуры аэрадромаў як пункты, вобласці з'яўлення |
| `objectives` | задачы бою, кожная з `type` (`capture_zone`, `airfield`, `helipad`, `base`, `spawn`, `convoy_spawn`, `battle_area`, `bombing_target`, `exit_zone`, `kill_area`, `rearm_zone`), `team` (1 або 2 запісу, пуста для абедзвюх), `name` (у зоны захопу яе літара, `A`), `shape` (`sphere`, `cylinder`, `box`, `point`, `points`, `outline`) з `position`, `radius` / `height` / `size` і `heading`, `source` (`replay` або `mission`) і тым, што яшчэ вядома (гл. [Задачы](objectives.md)) |
| `kills`, `hits`, `modulesDestroyed` | з назвамі і машынамі абодвух бакоў; забойствы з англійскай назвай зброі |
| `weapons` | кожная ракета, рэактыўны снарад, бомба, тарпеда, падвесны бак і скінуты груз: калі, дзе выпушчана (пазіцыя, арыентацыя, хуткасць), якой адзінкай (бліжэйшай у межах 300 м і 1,5 с), колькі адлікаў палёту, дзе бачна ў апошні раз, калі выдалена |
| `explosions`, `flak` | `PlayExplosionVisual` (пазіцыя, напрамак, від) і `PlayFlakExplosionVisual` (пазіцыя) |
| `awards` | узнагароды гульца, які вядзе запіс (`TextStreak`: first_blood, серыі, лічыльнікі выклікаў) |
| `detections`, `unitStates` | пары адзінак `UnitDetected`; паведамленне (0xF093) з пазіцыяй, арыентацыяй і хуткасцю адзінкі, сэнс якога невядомы |
| `authorInstruments` | значэнні кабіны гульца, які вядзе запіс (`ReplayCockpitParams`), па нумары прыбора, не болей аднаго ў секунду; `known` называе кожны нумар, дасланы гэтым запісам (назва, адзінка, як правярана), `notNamed` - астатнія |
| `scoreboard` | статыстыка кожнага гульца пры кожнай змене (забойствы, смерці, садзейнічанні, ачкі, забойствы ШІ, марскія забойствы, зоны, страты, ухіленні ад ракет, атрад) і ачкі кожнай каманды з верагоднымі білетамі ў часе (гл. [Дадзеныя рэфлексіі](aircraft.md#reflection-data)) |
| `economy` | Silver Lions і ачкі даследавання бою (гл. [Эканоміка](economy.md)): вынікі, на гульца, на машыну, множнікі, пераможца, праверкі |
| `entityMessages` | паведамленні сутнасцей (0x20) па нумары класа: колькасць, шаблоны мэт, памеры |
| `chat` | кожны радок чата |
| `triggers`, `hints`, `missionProgress` | дзеянні скрыпта місіі (RunTriggerAction), яго падказкі, паведамленні пра ход |
| `camera` | палі камеры запісу гульца, які вядзе запіс, кожныя 0,25 с, як дасланы (у табліцы яна ёсць як трэк) |
| `projectileHitReplays` | уласныя трапленні гульца, які вядзе запіс, і трапленні ў яго, са зброяй і боепрыпасамі і іх англійскімі назвамі |
| `results` | увесь blk вынікаў, як яго запісала гульня |
| `counts` | радкі, падзеі, жыцці, віды, адлікі, сутнасці па шаблоне, зброя, пакеты прачытаныя і не прачытаныя, кожны убачаны id паведамлення і не прачытаныя, адкінутыя адлікі |
| `trackBreaks` | кожны разрэз трэка за крок, хутчэйшы за магчымы для адзінкі: дзе, наколькі далёка, наколькі хутка і што гэта, хутчэй за ўсё |
| `selfCheck` | праверкі, пералічаныя ў [Як чытаецца запіс](how-it-reads.md), вылічаныя пры кожным канвертаванні; `stepSpeed` дае па відзе хуткасць паміж суседнімі радкамі трэка, як іх злучае праглядальнік (медыяна, 99-ы працэнтыль, найвышэйшая і крокі хутчэйшыя за магчымае, якіх павінна быць 0) |
