# Документ матчу {#the-match-document}

![Початок синтетичного документа матчу і його ключі](../assets/img/match-document.svg)

`<match>.match.json` містить усе, що повтор розповідає і що не є рядком таблиці.
Вкладка Match переглядача читає саме його.

## Бій {#the-battle}

| Ключ | Що це |
|---|---|
| `format`, `version` | `heat3d-wt-replay-match`, `2` |
| `match`, `map`, `level` | ідентифікатор матчу (як у назві файлу); ідентифікатор карти; файл рівня, який вона використовує |
| `mission`, `missionKey` | назва місії і її ключ у текстових файлах гри |
| `battleClass`, `environment`, `weather` | як їх дає заголовок |
| `sessionId`, `server` | ідентифікатор сесії бою; сервер |
| `replayVersion`, `flightLayout` | версія формату повтору; прочитана розкладка пакетів польоту (`2025` або `2026`) |
| `files` | прочитані файли повтору (один або частини серверного повтору) |
| `started`, `timePlayed`, `replayEnd` | час початку (ISO, UTC); секунди гри, за результатами; секунди останнього пакета повтору |
| `author`, `authorUserId` | гравець, що записав повтор, і його ідентифікатор Gaijin (клієнтські повтори) |
| `teams` | команди в бою (`1`, `2`) |
| `result` | `winner`, `status` (`success` або `fail`, результат автора), `authorTeam`, `teams` ([Економіка](economy.md)) |
| `vehicleNames` | звідки взялися назви техніки (ваше встановлення) і їхня мова |
| `conventions` | одиниці і знаки таблиці: осі, час, життя, трек, живий, крен та інше |

## Усе інше {#everything-else}

| Ключ | Що це |
|---|---|
| `battle`, `difficulty`, `gameMode` | режим бою: `difficulty` `AB` / `RB` / `SB` (і його назва, і байт заголовка), `gameMode` `ground` / `air` / `naval`, режим місії (`Dom`, `Conq`, `Bttl`, `I2M`, ...) і його англійська назва з вашого встановлення (`Domination`, `Enduring Confrontation`), дозволені типи юнітів (див. [Режим бою](ground.md#battle-mode)) |
| `settings` | блок місії після заголовка: режим, середовище, погода, ліміти рахунку і часу, країни, дозволені типи юнітів, вітер, і `stars` (широта, довгота, дата, місцевий час) |
| `sky` | перший `CustomWeatherParams`: напрямок сонця і місяця, вітер, кольори неба, зсуви хмар |
| `players`, `slots` | рядок результатів на кожного гравця (вбивства, наземні вбивства, смерті, допомога, рахунок, захоплення, загін, клан, країна, склад, uid техніки, якою він керував); слоти гравців у повторі (назва, ідентифікатор користувача, команда) |
| `units` | кожна сутність юніта, яку створив повтор: eid, uid, шаблон, техніка, вид, тип, команда, гравець, назва місії, коли створено і знищено, де створено, які компоненти не вдалося прочитати |
| `objects` | іменовані об'єкти місії: зони захоплення і аеродроми з їхнім положенням і розміром, контури аеродромів як точки, зони появи |
| `objectives` | цілі бою, кожна з `type` (`capture_zone`, `airfield`, `helipad`, `base`, `spawn`, `convoy_spawn`, `battle_area`, `bombing_target`, `exit_zone`, `kill_area`, `rearm_zone`), `team` (1 або 2 з повтору, порожньо для обох), `name` (для зони захоплення її літера, `A`), `shape` (`sphere`, `cylinder`, `box`, `point`, `points`, `outline`) з `position`, `radius` / `height` / `size` і `heading`, `source` (`replay` або `mission`) і все інше, що відомо (див. [Цілі](objectives.md)) |
| `kills`, `hits`, `modulesDestroyed` | з назвами і технікою обох сторін; вбивства з англійською назвою зброї |
| `weapons` | кожна ракета, керована ракета, бомба, торпеда, підвісний бак і скинуте навантаження: коли, де скинуто (положення, орієнтація, швидкість), яким юнітом (найближчим у межах 300 м і 1,5 с), скільки відліків польоту, де востаннє бачено, коли зник |
| `explosions`, `flak` | `PlayExplosionVisual` (положення, напрямок, вид) і `PlayFlakExplosionVisual` (положення) |
| `awards` | нагороди гравця, що записав повтор (`TextStreak`: перша кров, серії, лічильники викликів) |
| `detections`, `unitStates` | пари `UnitDetected` юнітів; повідомлення (0xF093) з положенням, орієнтацією і швидкістю юніта, значення якого невідоме |
| `authorInstruments` | значення кабіни гравця, що записав повтор (`ReplayCockpitParams`) за номером приладу, не більше одного на секунду; `known` називає кожен номер, який надіслав цей повтор (назва, юніт, як перевірено), `notNamed` — решту |
| `scoreboard` | статистика кожного гравця щоразу, коли вона змінювалась (вбивства, смерті, допомога, рахунок, вбивства ШІ, морські вбивства, зони, шкода, ухилення від ракет, загін), і рахунок кожної команди та ймовірні квитки в часі (див. [Дані відображення](aircraft.md#reflection-data)) |
| `economy` | срібні леви і дослідницькі очки бою (див. [Економіка](economy.md)): підсумки, за гравцями, за технікою, множники, переможець, перевірки |
| `entityMessages` | повідомлення сутностей (0x20) за номером класу: кількість, цільові шаблони, розміри |
| `chat` | кожен рядок чату |
| `triggers`, `hints`, `missionProgress` | дії сценарію місії (RunTriggerAction), її підказки, її повідомлення про хід місії |
| `camera` | поля камери повтору гравця, що записав повтор, кожні 0,25 с, як їх надіслано (таблиця має її як трек) |
| `projectileHitReplays` | власні влучання гравця, що записав повтор, і влучання в нього, зі зброєю і боєприпасами та їхніми англійськими назвами |
| `results` | увесь блок результатів у тому вигляді, в якому його записала гра |
| `counts` | рядки, події, життя, види, відліки, сутності за шаблоном, зброя, пакети прочитані і не прочитані, кожен побачений id повідомлення і ті, що не прочитані, відліки, відкинуті на місці |
| `trackBreaks` | кожен розрив треку через крок швидший, ніж юніт може пройти: де, наскільки далеко, як швидко і що це найімовірніше |
| `selfCheck` | перевірки, перелічені в [Як читається повтор](how-it-reads.md), обчислені під час кожного перетворення; `stepSpeed` дає за видом швидкість між сусідніми рядками треку, як їх з'єднує переглядач (медіана, 99-й перцентиль, найвища, і кроки швидші за можливі, яких має бути 0) |
