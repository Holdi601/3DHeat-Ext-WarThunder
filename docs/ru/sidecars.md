# Вспомогательные файлы и полнота {#sidecars-and-completeness}

Ничего из реплея не выбрасывается. То, что читает преобразователь, попадает в таблицу
и в документ матча; всё остальное сохраняется целиком в трёх вспомогательных файлах
рядом с таблицей (внутри файла `.3dheat` или отдельно с `--loose`). Это правило, общее
для всех преобразователей 3DHeat:
[Преобразователи сохраняют всё](https://holdi601.github.io/3DHeat/converters.html).

## Вспомогательные файлы {#the-sidecars}

- `<match>.messages.parquet`: каждое сообщение для единицы (время, id и название
  сообщения, uid, eid, шаблон, техника, её поля id в шестнадцатеричном виде, `decoded`
  (что из него прочитано, в виде JSON), полезная нагрузка), каждое реплицированное
  значение компонента (`name` — компонент, `fields` — его значение), каждое сообщение
  сущности (с номером её сущности и класса), каждый реплицированный объект
  (`ReflectionData <kind>/<index>`, его поля в шестнадцатеричном виде) и каждый пакет,
  который никакой читатель здесь не берёт, целиком.
- `<match>.objectives.parquet`: зоны захвата во времени, одна строка на каждое
  изменение, которое прислал сервер: `time`, `event` (`state`, `progress`, `captured`,
  `neutralised`), `zone` (её буква), `zoneId`, `object`, `owner` (0 — нет, 1, 2),
  `progress` (-100..100, положительные — в сторону команды 2), `x`, `y`, `z` зоны и все
  `fields` объекта в шестнадцатеричном виде (см. [Цели](objectives.md)).
- `<match>.flight.parquet`: каждая запись модели полёта каждого самолёта целиком (её
  биты и `phase`: бит первого байта, с которого она началась), с её скоростью, 14
  полубайтами управления (`control1-3`, `throttle`), её двигателями с их состоянием,
  форсажем и исправностью, и её запасом снарядов по каждому оружию (`ammo`; `numbers` —
  полный список). Значения других самолётов — такие, какими они были при последнем
  обновлении.

## Что гарантируют подсчёты {#what-the-counts-guarantee}

Поля `counts` документа матча говорят, что содержал реплей и что с этим стало:

| Ключ | Что |
|---|---|
| `packets`, `unreadPackets` | каждый встреченный тип пакета и те, которые не берёт ни один читатель (сохраняются целиком во вспомогательном файле сообщений) |
| `messageIds`, `messageIdsNotRead` | каждый встреченный id сообщения и сколько раз, а также те, которые только сохраняются, но не читаются |
| `replicatedComponents`, `replicatedNotRead` | прочитанные значения компонентов и те, которые только сохраняются |
| `entities`, `entityTemplates`, `entityMessages` | что создал и отправил поток сущностей |
| `droppedSamples` | выборки, намеренно пропущенные (обломки наземной техники после того, как её сущность исчезла), с указанием причины |

Больше ничего не пропускается: каждый элемент реплея либо прочитан в таблицу или в
документ матча, либо сохранён целиком во вспомогательном файле. Раздел `selfCheck`
документа матча содержит проверки того, что было прочитано
([Как читается реплей](how-it-reads.md)).
