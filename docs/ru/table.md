# Таблица {#the-table}

![Таблица синтетического реплея, кратко](../assets/img/table.svg)

Одна строка на выборку или событие, 105 столбцов ([Список столбцов](../columns.md), создан из кода);
в подвале, под `heat3d`, — инструкции просмотрщику по чтению, поэтому просмотрщику не нужно ничего
заполнять вручную.

| Столбец | Что |
|---|---|
| `time` | секунды по собственным часам реплея |
| `event` | `position`; строки событий лежат на треке в свой момент (между двумя выборками — на линии между ними); `kill` (у убийцы), `death` (у жертвы), `hit_critical` / `hit_severe` (у поражённого юнита), `module_destroyed` (у юнита), `launch` (у юнита, который отпустил оружие), `impact` (последняя выборка оружия, когда его удалили сразу после); `explosion` и `flak` (0xD08E, 0xD01F) в своём положении, вид `effect`, без трека, с направлением взрыва там, где оно есть; `shot` (снаряд, который попал, у стрелявшего), `gun_shot`, `fire_start`, `fire_stop` (очередь орудия, а не горящая техника), `fire_on`, `fire_off` (горящая техника, см. [Пожары техники](hits.md#vehicle-fires)), `reward` (заработанные Silver Lions и очки исследований, см. [Экономика](economy.md)), `dead`, `bailout`, `repair`, `rearm`, `bullet_rearm`, `reload` (см. [Сообщения юнитам](how-it-reads.md#messages-to-units)); `despawn` — последняя строка трека, чей юнит исчез до конца реплея (см. [Конец трека](ground.md#end-of-a-track)) |
| `track` | то, что просмотрщик рисует как одно целое: одна жизнь юнита или полёт одного снаряда — `<player or vehicle> #<hex>` (просмотрщик показывает название без части `#`) |
| `x`, `y`, `z` | метры игры: x — восток, y — вверх, z — север (подсказки отражают z, поэтому север не рисуется на юг) |
| `player` | имя игрока; у юнита ИИ — `<VehicleName> #<uid>` (например, `F-15A #204`); `uid <n>`, если ничто его не называет; у оружия — кто его отпустил |
| `userId`, `team` | id Gaijin игрока и команда (`1`, `2`) |
| `ai`, `isPlayer` | `ai` равно true для каждого юнита, которым не управляет ни один игровой аккаунт (юниты задания, самолёты ИИ, наземные цели, зенитки, корабли без игрока, заглушки), `isPlayer` — противоположное: игрок — это юнит, сущность которого называет слот игрока с id Gaijin. У оружия — как у его пусковой установки; пусто, когда неизвестно |
| `match` | id матча (`match` документа матча) в каждой строке; подсказки используют его как сессию, поэтому два загруженных реплея никогда не соединяют треки |
| `life` | `uid#n`: трек одного юнита, разрезанный там, где uid переходит к другому юниту, юнит движется быстрее, чем может (возрождение, перезарядка, перемещение игрой, поправка клиентом далёкого юнита; см. Телепортации в [Как читается реплей](how-it-reads.md#what-is-read-and-the-check)), или долго не виден; `w<hex>` — полёт оружия (`w<hex>#n` после разреза) |
| `uid` | id юнита в реплее |
| `kind` | `aircraft`, `helicopter`, `tank`, `apc`, `spaa`, `truck`, `ship`, `boat`, `structure`, `train` (трамвай или вагон, которые размещает уровень, см. [Сценические юниты](objectives.md#scene-units-trams-and-rail-wagons)); оружие: `missile`, `rocket`, `bomb`, `torpedo`, `payload`, `jettisoned`; `camera` — камера реплея игрока (см. [Камера](ground.md#the-camera)) |
| `type` | собственный тип игры там, где его называют результаты (`fighter`, `assault`, `destroyer`, `gun_boat`), иначе как `kind` |
| `Vehicle` | идентификатор техники в игре (`f_15a`, `germ_flakpz_I_Gepard`), по которому подбираются фигуры просмотрщика |
| `VehicleName`, `VehicleShortName`, `VehicleNameKey` | английское название техники из локализации вашей установки (`Pz.Kpfw. III Ausf. J1`, короткое `Pz.III J1`) и её ключ (`germ_pzkpfw_III_ausf_J_0`); знаки стран шрифта игры не включаются. Там, где игра ничего не называет или установка не найдена, название — это идентификатор, а ключ пуст |
| `mission` | название юнита в задании (`t1_tank_05`, `t2_player03_0`) |
| `dirX`, `dirY`, `dirZ` | куда смотрит юнит (вектор взгляда): у самолётов — из ориентации модели полёта, у наземных юнитов и кораблей — из их собственной, у оружия — вдоль его полёта |
| `heading`, `pitch`, `roll` | то же в градусах; курс — компас, по часовой стрелке от севера, тангаж — нос вверх положительный, крен — правое крыло вниз положительный (модель полёта присылает знак наоборот, см. [Ориентация, проверено](aircraft.md#attitude-checked); у наземного юнита — правый борт вниз). Подсказки говорят об этом в `conventions` |
| `turretYaw`, `gunPitch`, `turrets` | главная башня танка — куда смотрит пушка, а не куда смотрит игрок; значение реплея, удержанное в скорости привода башни и установленное на линию каждого выстрела главной пушки (см. [Башни](ground.md#turrets)): её поворот относительно корпуса (градусы, по часовой стрелке при взгляде сверху — положительный, 0 — прямо вперёд) и наклон её пушки относительно корпуса (градусы, вверх — положительный); `turrets` — каждая башня техники как `yaw pitch;yaw pitch;...` в её собственном порядке (неиспользуемый слот читается как `0.00 0.00`). Танки, зенитки SPAA, бронетранспортёры и грузовики, в клиентских и серверных реплеях; не корабли (см. [Башни](ground.md#turrets)) |
| `turretYawRaw`, `gunPitchRaw` | главная башня так, как её присылает реплей; `turretYaw` / `gunPitch` — та же башня, удержанная в скорости привода и установленная на линию каждого выстрела главной пушки (см. [Башни](ground.md#turrets)) |
| `viewYaw`, `viewPitch` | куда смотрит игрок (прицеливается камерой) в мире: градусы компаса (0 — север, по часовой стрелке) и градусы вверх, та же условность, что и у `aimHeading` / `aimPitch` (в отличие от `turretYaw` / `gunPitch`, которые остаются относительными к корпусу). Танк каждого игрока в серверном реплее, собственный танк игрока, который записал реплей, в клиентском; пусто там, где игрок никуда не целится (все четыре значения прицела равны 0). Башня следует за ним со своей скоростью поворота, поэтому они различаются, пока она поворачивается (см. [Башни](ground.md#turrets)) |
| `aimHeading`, `aimPitch`, `aimDistance` | собственный танк игрока, который записал реплей: куда он целится (градусы компаса, градусы вверх, дальность в м; 2000, когда в прицеле ничего нет); строки камеры: куда целится игрок (курс, тангаж) |
| `zoom` | строки камеры: увеличение камеры (см. [Камера](ground.md#the-camera)) |
| `difficulty`, `gameMode` | `AB`, `RB` или `SB` боя и `ground`, `air` или `naval` — в каждой строке (см. [Режим боя](ground.md#battle-mode)) |
| `extrapolated` | выборка самолёта, которая является счислением клиента, а не полученным состоянием (см. [Счисление пути](aircraft.md#dead-reckoning-and-the-smoother)); выборка бомбы, вычисленная от её отпуска (см. Бомбы без записей полёта в [Как читается реплей](how-it-reads.md#what-is-read-and-the-check)) |
| `moved`, `xRaw`, `yRaw`, `zRaw`, `headingRaw`, `pitchRaw`, `rollRaw` | насколько сглаживание сдвинуло выборку (м), и собственные положение и ориентация реплея (крен — со знаком таблицы) |
| `targetX`, `targetY`, `targetZ` | точка попадания `shot` |
| `hitOutcome`, `hitFlags` | исход `shot` по наземному юниту: `kill`, `critical`, `penetration` или `nonpenetration` (отскок или остановка: реплей не отличает рикошет), по битам, которые сервер присылает с попаданием (`hitFlags`, сырые); пусто там, где ничего не присылается (самолёты, корабли). См. [Исходы попаданий](hits.md#hit-outcomes) |
| `hitShell` | сигнатура снаряда `shot`: четыре байта сообщения о попадании (сырой hex); одна сигнатура может обозначать разные снаряды (120 и 125-мм APFSDS имеют одну), поэтому она хранится сырой, а не читается как калибр |
| `ammoType`, `ammoName`, `ammoSlot`, `calibre` | боеприпасы `shot`: их тип (`APFSDS`, `APDS`, `HE`, `HEAT-FS`, `HESH`, `ATGM`...) и id (`125mm_3bm46`) там, где убийство называет слот стрелявшего, иначе `explosive` (взрывной пакет попаданий) или `kinetic`; `weapon/slot` орудия по его перезарядкам; калибр в мм из файлов оружия установки. См. [Исходы попаданий](hits.md#hit-outcomes) |
| `rpm` | обороты двигателя самолёта (среднее по его двигателям), как они присланы последний раз, в пределах 2 с |
| `vx`, `vy`, `vz` | скорость самолёта, как её присылает его запись полёта (м/с, оси игры; скорости больше 500 м/с читаются как 500) |
| `engine`, `afterburner`, `engineCondition` | двигатели самолёта из его записи полёта: `off`, `starting`, `running`, `dead` (через `/`, когда его двигатели различаются); форсаж 0-1; байт, который присылается только после попадания в двигатель |
| `weaponName` | убийства и смерти: оружие или боеприпас на английском из вашей установки (`AIM-120C-5 AMRAAM air-to-air missiles`, `Fragmentation incendiary tracer shell`) |
| `throttle`, `elevator`, `aileron`, `rudder`, `ammo` | только самолёт игрока, который записал реплей: газ 0-1.1 из его кабины (1.1 — боевой аварийный режим или форсаж; иначе — пятнадцатые из его записи полёта), органы управления -1..1 из его записи полёта (руль высоты, положительный — на себя; элерон, положительный — крен вправо), оставшиеся снаряды по каждому оружию (`250 140 170`) |
| `ias`, `vario`, `fuel`, `manifoldPressure`, `gear`, `oilTemperature`, `headTemperature` | только самолёт игрока, который записал реплей, из его кабины: индикаторная воздушная скорость и вертикальная скорость (м/с), топливо, давление наддува (атм), шасси (0-1, 1 — выпущено), температура масла и головок цилиндров, там, где кабина имеет этот прибор |
| `speed` | м/с за около две секунды трека (вычисляется здесь; реплей не присылает скорость для других юнитов) |
| `alive` | 0 у выборок юнита после его смерти (его обломки): у наземного юнита или корабля — пока игра его не удалит или его выборки не закончатся, у самолёта — не дольше 60 с |
| `otherVehicle`, `otherLife` | жертва `shot`: её техника и её `life` |
| `hitLocalX`, `hitLocalY`, `hitLocalZ`, `hitDirX`, `hitDirY`, `hitDirZ` | точка попадания `shot` в собственной системе координат жертвы (м; x вперёд, y вверх, z влево; см. [Сообщения юнитам](how-it-reads.md#messages-to-units)) и направление, с которого пришёл выстрел, пересчитанное в эту систему ориентацией жертвы на тот момент |
| `hitPart`, `hitFlag` | сообщение о попадании `shot`: его слово части, как оно прислано, и его старший байт |
| `cost_fired_sl`, `cost_lost_sl`, `earn_sl`, `earn_rp`, `rewardType`, `currency`, `econ_basis`, `won` | что стоил и что принёс бой и кто выиграл: см. [Экономика](economy.md) |
| `other`, `weapon` | убийства: другая сторона и оружие; попадания: кто попал (из uid записи, иначе из слота игрока) и их техника; пуски: оружие; выведенные из строя модули: кто последним попал в юнит за 5 с до этого, и `part <n>` |
