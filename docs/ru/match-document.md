# Документ матча {#the-match-document}

![Начало синтетического документа матча и его ключи](../assets/img/match-document.svg)

`<match>.match.json` содержит всё, что говорит реплей и что не является строкой
таблицы. Вкладка «Матч» просмотрщика читает именно этот файл.

## Бой {#the-battle}

| Ключ | Что |
|---|---|
| `format`, `version` | `heat3d-wt-replay-match`, `2` |
| `match`, `map`, `level` | id матча (как в имени файла); id карты; файл уровня, который она использует |
| `mission`, `missionKey` | название задания и его ключ в текстовых файлах игры |
| `battleClass`, `environment`, `weather` | как их задаёт заголовок |
| `sessionId`, `server` | id сессии боя; сервер |
| `replayVersion`, `flightLayout` | версия формата реплея; прочитанная раскладка пакетов полёта (`2025` или `2026`) |
| `files` | прочитанные файлы реплея (один, или части серверного реплея) |
| `started`, `timePlayed`, `replayEnd` | время начала (ISO, UTC); сколько секунд сыграно, по результатам; сколько секунд длится последний пакет реплея |
| `author`, `authorUserId` | игрок, который записал реплей, и его id Gaijin (клиентские реплеи) |
| `teams` | команды в бою (`1`, `2`) |
| `result` | `winner`, `status` (`success` или `fail`, исход автора), `authorTeam`, `teams` ([Экономика](economy.md)) |
| `vehicleNames` | откуда взяты названия техники (ваша установка) и их язык |
| `conventions` | единицы измерения и знаки таблицы: оси, время, жизнь, трек, живой, крен и другое |

## Всё остальное {#everything-else}

| Ключ | Что |
|---|---|
| `battle`, `difficulty`, `gameMode` | режим боя: `difficulty` `AB` / `RB` / `SB` (с названием и байтом заголовка), `gameMode` `ground` / `air` / `naval`, режим задания (`Dom`, `Conq`, `Bttl`, `I2M`, ...) и его английское название из вашей установки (`Domination`, `Enduring Confrontation`), разрешённые типы техники (см. [Режим боя](ground.md#battle-mode)) |
| `settings` | блок задания после заголовка: режим, среда, погода, лимиты очков и времени, страны, разрешённые типы техники, ветер и `stars` (широта, долгота, дата, местное время) |
| `sky` | первый `CustomWeatherParams`: направление солнца и луны, ветер, цвета неба, смещения облаков |
| `players`, `slots` | строка результатов на каждого игрока (убийства, убийства наземной техники, смерти, помощь, очки, захваты, отряд, клан, страна, состав, uid техники, которой он управлял); слоты игроков реплея (имя, id пользователя, команда) |
| `units` | каждая сущность-единица, которую создал реплей: eid, uid, шаблон, техника, вид, тип, команда, игрок, название в задании, когда создана и удалена, где создана, какие компоненты не удалось прочитать |
| `objects` | именованные объекты задания: зоны захвата и аэродромы с их положением и размером, контуры аэродромов как точки, зоны появления |
| `objectives` | цели боя, каждая с `type` (`capture_zone`, `airfield`, `helipad`, `base`, `spawn`, `convoy_spawn`, `battle_area`, `bombing_target`, `exit_zone`, `kill_area`, `rearm_zone`), `team` (1 или 2 из реплея, пусто для обеих), `name` (у зоны захвата — её буква, `A`), `shape` (`sphere`, `cylinder`, `box`, `point`, `points`, `outline`) с `position`, `radius` / `height` / `size` и `heading`, `source` (`replay` или `mission`) и всё, что ещё известно (см. [Цели](objectives.md)) |
| `kills`, `hits`, `modulesDestroyed` | с названиями и техникой обеих сторон; убийства с английским названием оружия |
| `weapons` | каждая ракета, управляемая ракета, бомба, торпеда, подвесной бак и сброшенный груз: когда, где отпущен (положение, ориентация, скорость), каким юнитом (ближайшим в пределах 300 м и 1.5 с), сколько выборок полёта, где видели в последний раз, когда удалён |
| `explosions`, `flak` | `PlayExplosionVisual` (положение, направление, вид) и `PlayFlakExplosionVisual` (положение) |
| `awards` | награды игрока, который записал реплей (`TextStreak`: первая кровь, серии, счётчики испытаний) |
| `detections`, `unitStates` | пары `UnitDetected` для юнитов; сообщение (0xF093) с положением, ориентацией и скоростью юнита, значение которого не известно |
| `authorInstruments` | значения кабины игрока, который записал реплей (`ReplayCockpitParams`), по номеру прибора, не более одного в секунду; `known` называет каждый номер, который прислал этот реплей (название, юнит, как проверено), `notNamed` — остальные |
| `scoreboard` | статистика каждого игрока каждый раз, когда она менялась (убийства, смерти, помощь, очки, убийства ИИ, морские убийства, зоны, урон, уклонения от ракет, отряд), и счёт каждой команды и вероятные билеты во времени (см. [Данные отражения](aircraft.md#reflection-data)) |
| `economy` | серебряные львы и очки исследований боя (см. [Экономика](economy.md)): итоги, по игроку, по технике, множители, победитель, проверки |
| `entityMessages` | сообщения сущностей (0x20) по номеру класса: количество, целевые шаблоны, размеры |
| `chat` | каждая строка чата |
| `triggers`, `hints`, `missionProgress` | действия сценария задания (RunTriggerAction), его подсказки, его сообщения о ходе |
| `camera` | поля камеры реплея игрока, который записал реплей, каждые 0.25 с, как они были отправлены (в таблице они есть как трек) |
| `projectileHitReplays` | собственные попадания игрока, который записал реплей, и попадания по нему, с оружием и боеприпасами и их английскими названиями |
| `results` | весь блок результатов в том виде, в каком его записала игра |
| `counts` | строки, события, жизни, виды, выборки, сущности по шаблонам, оружие, пакеты прочитанные и непрочитанные, каждый встреченный id сообщения и непрочитанные, отброшенные выборки |
| `trackBreaks` | каждый разрыв трека из-за шага быстрее, чем может пройти юнит: где, на сколько, как быстро и что это, вероятнее всего |
| `selfCheck` | проверки, перечисленные в [Как читается реплей](how-it-reads.md), вычисляются при каждом преобразовании; `stepSpeed` даёт по каждому виду скорость между соседними строками трека так, как их соединяет просмотрщик (медиана, 99-й перцентиль, наибольшая и шаги быстрее возможного, которых должно быть 0) |
